## 🩺 Troubleshooting: Fixing Temporal Anomalies

We ocassionally encounter "Reality Drift" where a game update changes the save schema.

- **Symptom:** The tool fails to identify the asset index.
- **Remedy:** Run the built-in "Schema Sniffer" (found in Settings > Archive). This utility scans the surrounding file architecture to infer the new data structure.
- **Symptom:** The Ripple Effect graph appears red.
- **Remedy:** This indicates significant data corruption. Use the "Paradox Rollback" feature in the Nexus Backup tab to restore the last stable state.
